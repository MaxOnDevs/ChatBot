# Esercizio di realizzazione di un Chatbot per un negozio di dischi fittizio

# Richiede :

- Python
- Ollama
- ChromaDb Embedding : nomic-embed-text
- Llm Qwen : qwen2.5:1.5b
- FastAPI

## Installare Ollama e ChromaDb

## Attivare progetto

## Comando per installare FastAPI
```bash
python -m pip install fastapi uvicorn

```

## Comando per avviare il Chatbot-app
```bash
python -m uvicorn main:app --reload

```
